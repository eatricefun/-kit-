# Kit 指令套装行为包（Minecraft 基岩版）v1.1.0

一个纯行为包（Behavior Pack）Addon，为基岩版加入类似服务器的 kit（套装）系统，单人存档可用：
用**大箱子（54 格）分区界面**自由搭配装备，一键穿戴，每位玩家独立拥有 9 个套装槽位。

## 配置箱分区（v1.1.0 新增）

`/k:kits n` 生成的配置箱是大箱子，54 格按行分区：

- 第 1 行前 5 格＝**穿戴区**：头盔 / 胸甲 / 护腿 / 靴子 / 副手（盾、图腾）
- 第 1 行后 4 格＋第 3~6 行＝**背包区**：穿戴后进入背包
- 第 2 行 9 格＝**快捷栏区**：穿戴后依次占你的快捷栏 1~9（被顶掉的原物品掉脚下）

空位上的蓝色"▲"纸片只是位置标签，可随意拿走；保存时自动剔除，不会存进套装。
若身边空间放不下大箱子对，会自动退化为单箱 27 格（分区顺序相应压缩）。

## 游戏内命令

| 命令 | 作用 |
| --- | --- |
| `/k:kits` | 打开第 1 套（或你上次编辑的那套）的配置箱 |
| `/k:kits 3` | 打开第 3 套的配置箱 |
| `/k:kit` | 一键穿戴第 1 套 |
| `/k:kit 2` | 一键穿戴第 2 套 |
| `/k:kitlist` | 打开套装管理菜单（新建 / 编辑 / 穿戴 / 删除） |
| `/k:kitsdel 5` | 清空第 5 套 |
| `/k:kitsdone` | 手动保存并收回配置箱（备用，正常关箱即自动保存） |

> 说明：基岩版的自定义命令强制要求带命名空间，因此无法做成纯 `/kits`，
> 这里用最简短的 `k:` 前缀。所有命令均无需 OP 权限（Any 级别），
> 但世界必须开启"作弊"（脚本 API 行为包本身也需要）。

## 使用流程

1. 站在平整开阔处，输入 `/k:kits`，面前会出现一个【套装 1 · 配置箱】。
2. 右键打开它，像整理普通箱子一样：把你的钻石套、附魔剑、食物等放进去；
   不想编进套装的东西取出来。
3. 关闭箱子，内容自动保存为 1 号套装。
4. 以后任何时候输入 `/k:kit`，瞬间穿戴/领取第 1 套。
   被替换下来的旧装备会掉在脚下，不会凭空消失；套装是可反复领取的"预设"。
5. 用 `/k:kits 2`、`/k:kits 3` 可以配置第 2、第 3 套……最多 9 套（可改配置）。
   `/k:kitlist` 菜单可以一览所有套装并点选操作。

## 安装

1. 把 `kit-套装行为包.mcpack` 使用Minecraft打开，等待导入。
2. 进入存档设置 → 行为包 → 启用 "Kit 指令套装行为包"。
3. 开启"作弊"开关（无需开启任何实验性玩法）。

## 版本要求

- Minecraft 基岩版 1.26 及以上（需要 @minecraft/server 稳定 API 2.8+，
  对应"自定义命令"与"容器开关箱事件"均已转正的版本）。
- 若游戏版本过旧，包会提示不兼容或脚本事件订阅失败。

## 技术要点（给想改造的人）

- 每个 kit 的数据本体 = 末地隐藏仓库区（坐标 1000,108,1000 层）的**一对合并大箱子**，
  物品经 `ItemStack` 引擎级复制，附魔/命名/耐久等全部 NBT 无损保留；
  v1.0.x 的旧单箱仓库数据会在首次打开对应套装时自动迁移进大箱子。
- 仓库区块用 `tickingarea` 常加载，并对破坏做了拦截保护。
- 配置箱是放在玩家身边的临时箱子，通过 `blockContainerClosed` 事件感知"关箱即保存"，
  保存 = 把配置箱内容全量镜像进仓库箱，然后收回配置箱并还原原方块。
- 槽位数、命名空间、仓库坐标、默认套装等参数集中在 `scripts/main.js` 顶部的 `CFG` 对象。
- 崩溃/断电恢复：配置箱状态写入玩家动态属性，重进世界会自动回收未保存的箱子。
